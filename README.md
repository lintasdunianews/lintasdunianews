# Lintas Dunia News

Tema awal portal berita Lintas Dunia News.

## Isi paket
- `index.html`: halaman depan responsif (prototipe visual).

## Catatan
Konten berita pada halaman ini masih berupa contoh. Dashboard admin, database, autentikasi, unggah media, dan publikasi dinamis akan dibangun pada tahap berikutnya menggunakan backend terpisah.

## Pratinjau lokal
Buka `index.html` di browser.
